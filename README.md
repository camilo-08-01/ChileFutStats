# ChileFutStats
Plataforma de estadísticas y pronósticos de la Primera División chilena

## 🚧 En construcción

Proyecto en desarrollo activo — siguiendo un plan de construcción por fases.

## Stack

- **Backend:** ASP.NET Core Web API (C#)
- **Base de datos:** Oracle / SQL Server + MongoDB
- **Autenticación:** JWT
- **Frontend:** HTML/CSS/JS
- **Datos:** API-Football
